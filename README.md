# Repair Planner

Программа для планирования ремонтных работ: сметы, задачи, сотрудники,
календарь. Здесь лежат только установщики, обновления программа скачивает
отсюда сама.

## Установка

1. Скачать [RepairPlanner-win-Setup.exe](https://github.com/ILepekhov/repair-planner-releases/releases/latest/download/RepairPlanner-win-Setup.exe)
   (последняя версия).
2. Запустить. Права администратора не нужны: программа ставится только для
   текущего пользователя Windows. Если на компьютере нет .NET, установщик
   скачает его сам.
3. Ярлык «Repair Planner» появится на рабочем столе и в меню «Пуск».

### Если Windows пишет «Windows защитила ваш компьютер»

Так SmartScreen реагирует на программы без платной цифровой подписи. Нажмите
**«Подробнее»** → **«Выполнить в любом случае»**. Это нужно только при
установке.

## Первый вход

Логин и **временный пароль** вам выдаст администратор программы.

1. Введите их и нажмите **«Войти»**.
2. Программа попросит **«Придумайте свой пароль»**: в поле «Текущий
   пароль» — временный, в «Новый пароль» — свой, не короче 8 символов, и
   повторите его.

Дальше программа помнит вход на этом компьютере, вводить пароль каждый раз
не нужно. Сменить пароль потом можно на странице **«Учётная запись»**.

**Забыли пароль** — попросите администратора его сбросить: он выдаст новый
временный, и при входе снова нужно будет придумать свой.

**«Слишком много неудачных попыток входа»** — после 5 неверных паролей
подряд вход блокируется на 15 минут. Подождите или попросите администратора
сбросить пароль.

## Обновления

Ничего делать не нужно. Программа сама проверяет обновления и скачивает их
фоном, потом показывает сообщение «Доступна версия …»:
- **«Перезапустить»** — программа перезапустится уже обновлённой;
- **«Позже»** — обновление установится, когда вы закроете программу.

Если программа сообщает **«Требуется обновление»**, нажмите **«Обновить»**:
текущая версия больше не работает с сервером.

## Если что-то не так

**«Нет связи с сервером»** — проверьте интернет. Программа сама повторяет
попытки и загрузит данные, когда связь появится. Если интернет есть, а связи нет
дольше нескольких минут — сообщите администратору.

**Ошибка или странное поведение** — напишите администратору, что делали и
что увидели (лучше со снимком экрана), и приложите файл журнала за этот
день: папка `%LocalAppData%\Planner.Desktop\logs` (вставьте этот путь в
адресную строку Проводника), файл `desktop-<дата>.log`.

## Удаление

«Параметры» → «Приложения» → «Установленные приложения» → Repair Planner →
«Удалить».
