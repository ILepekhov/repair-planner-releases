# Repair Planner

Программа для планирования ремонтных работ: сметы, задачи, сотрудники,
календарь. Здесь лежат только установщики, обновления программа скачивает
отсюда сама.

## Установка

1. Скачать [RepairPlanner-win-Setup.exe](https://github.com/ILepekhov/repair-planner-releases/releases/latest/download/RepairPlanner-win-Setup.exe)
   (последняя версия).
2. Запустить. Права администратора не нужны: программа ставится только для
   текущего пользователя Windows. Если на компьютере нет .NET, установщик
   скачает его сам.
3. Ярлык «Repair Planner» появится на рабочем столе и в меню «Пуск».

### Если Windows пишет «Windows защитила ваш компьютер»

Так SmartScreen реагирует на программы без платной цифровой подписи. Нажмите
**«Подробнее»** → **«Выполнить в любом случае»**. Это нужно только при
установке.

## Обновления

Ничего делать не нужно. Программа сама проверяет обновления и скачивает их
фоном, потом показывает сообщение «Доступна версия …»:
- **«Перезапустить»** — программа перезапустится уже обновлённой;
- **«Позже»** — обновление установится, когда вы закроете программу.

Если программа сообщает **«Требуется обновление»**, нажмите **«Обновить»**:
текущая версия больше не работает с сервером.

## Удаление

«Параметры» → «Приложения» → «Установленные приложения» → Repair Planner →
«Удалить».
